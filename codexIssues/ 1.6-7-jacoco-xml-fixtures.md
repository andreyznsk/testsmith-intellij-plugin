## Title

Iteration 1 / Feature 1.6–1.8: JaCoCo XML fixtures + Maven XML parser contracts + unit tests

## Context

Нужно реализовать базовый слой coverage-driven агента: чтение JaCoCo XML (Maven) → snapshot → выбор weakest class.
Проектный root package: `io.testsmith.plugin`.

Главные принципы:

* детерминизм
* расширяемые интерфейсы
* безопасность (никаких silent fallback)
* никакого IntelliJ/PSI на этом шаге

## Scope

### ✅ Must

1. Добавить XML fixtures в `src/test/resources/jacocoTest/`
2. Реализовать immutable domain model snapshot’а
3. Реализовать `JacocoXmlCoverageReader` (DOM/StAX, НЕ regex)
4. Реализовать `DefaultCoverageFilter` и `LowestLineCoveragePolicy`
5. Написать unit-тесты по fixtures + failure modes

### ❌ Must NOT

* PSI / IntelliJ API
* анализ `.class`
* парсинг методов / sourcefile
* эвристики “с умом”
* тихие fallback’и

    Optional<ClassCoverage> select(CoverageSnapshot snapshot);

**Domain records**

```java

import java.util.Map;

public record CoverageSnapshot(
    Map<String, PackageCoverage> packages
) {}
```

```java
package io.testsmith.plugin.coverage;

import java.util.Map;

public record PackageCoverage(
    String packageName,
    Map<String, ClassCoverage> classes
) {}
```

```java
package io.testsmith.plugin.coverage;

public record ClassCoverage(
    String className, // fully qualified
    LineCoverage lineCoverage
) {}
```

```java
package io.testsmith.plugin.coverage;

public record LineCoverage(int missed, int covered) {
    public int total() { return missed + covered; }
    public double ratio() { return total() == 0 ? 1.0 : (double) covered / total(); }
}
```

**Invariants**

* missed/covered >= 0 (валидировать на чтении)
* FQCN = package (слэши→точки) + "." + className

## Unit tests (must)

Тесты должны читать fixtures из `src/test/resources/jacocoTest/...` как resource → Path.

Проверить:

1. **Happy path**

* packages = 2
* classes total = 5
* FQCN корректные
* `com.acme.service.OrderService` → missed=7, covered=3

2. **Missing LINE counter**

* класс `HasOnlyInstruction` отсутствует в snapshot
* `com.acme.service.Normal` присутствует

3. **Zero total ratio**

* `EmptyCoverage.total() == 0`
* `EmptyCoverage.ratio() == 1.0`

4. **Exclusion rules + selection**

* после фильтра остаётся только `com.acme.domain.Invoice`
* policy.select(...) возвращает Invoice

5. **Tie-breaker selection**

* policy.select(...) возвращает `com.acme.service.BService`

6. **Failure modes**

* если файла нет → exception
* если XML битый → exception (добавить небольшой inline temp-file test)
